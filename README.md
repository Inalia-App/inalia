# inalia

[![npm version][npm-version-src]][npm-version-href]
[![npm downloads][npm-downloads-src]][npm-downloads-href]

The official CLI for [Inalia](https://inalia.app), to use and set up [slidev-addon-inalia](https://github.com/Inalia-App/slidev-addon-inalia).

## Setup

Run this command in your Slidev project:

```sh
npx inalia slidev setup
```

The CLI signs you in, lets you choose a talk, installs `slidev-addon-inalia`, and configures your deck.

## Official Documentation

Documentation is maintained in [Inalia-App/inalia.app](https://github.com/Inalia-App/inalia.app) and published on the [official documentation site](https://docs.inalia.app/slidev-addon-inalia).
